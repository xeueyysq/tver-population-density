Учебный проект.

Интерактивная карта плотности населения районов Тверской области, 2025.
Сделана в QGIS 4.2.3, выгрузка плагином qgis2web 3.30.0 (Leaflet).
Всплывающие окна показывают название района, население, площадь и плотность.
Доступны поиск по названию района, метрическая линейка и легенда.

Дисциплина: Геоинформационные технологии в системе управления.
Университет Дубна, Институт системного анализа и управления (ИСАУ).
Автор: Кулик И.В., гр. 5011, 2026.

Страница карты: https://xeueyysq.github.io/tver-population-density/

Источники данных и условия использования:

- Росстат: [раздел Демография](https://rosstat.gov.ru/folder/12781), [таблица численности населения на 01.01.2025](https://rosstat.gov.ru/storage/mediabank/%D0%A1hisl_MO_01-01-2025.xlsx), лист Численность_по_МО. Использованы опубликованные статистические данные с указанием источника; отдельная открытая лицензия на таблицу не указана.
- Границы: OpenStreetMap contributors через [geoBoundaries, RUS ADM2](https://www.geoboundaries.org/api/current/gbOpen/RUS/ADM2/), геометрия 2017 года. Лицензия [Open Data Commons Open Database License (ODbL) 1.0](https://www.openstreetmap.org/copyright).

Площадь рассчитана в равновеликой проекции EPSG:8857, плотность равна населению, деленному на площадь в км². Состав территорий согласован с таблицей Росстата; изменения местоположения границ после 2017 года не восстановлены.
